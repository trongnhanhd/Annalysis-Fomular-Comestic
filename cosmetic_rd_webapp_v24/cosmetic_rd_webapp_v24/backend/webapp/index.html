KẾT NỐI

Cài đặt API thư viện

Máy chủ API đang chạy cùng tên miền với giao diện. Nếu API thư viện yêu cầu khóa, nhập khóa vào đây; chỉ lưu trong phiên trình duyệt.

Không dùng khóa API chung này cho môi trường production có nhiều người dùng; cần xác thực tài khoản và phân quyền trên máy chủ.
